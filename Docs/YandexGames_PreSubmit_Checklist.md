# Чеклист Перед Отправкой в Яндекс Игры (SweetTrio)

Дата: 29.03.2026

## 1) Билд и архив
- [ ] Целевая платформа сборки: `WebGL`, release-конфигурация.
- [ ] В корне ZIP-архива лежит `index.html` (не во вложенной папке).
- [ ] Размер распакованной сборки <= 100 MB.
- [ ] В итоговом архиве нет кириллицы и пробелов в именах файлов/папок.
- [ ] `index.html` открывается локально без критических JS-ошибок в консоли браузера.

## 2) Интеграция SDK
- [x] Плагин Яндекса подключен (`PLUGIN_YG_2`, `YandexGamesPlatform_yg`).
- [x] Автоматический `GameReady` включен (`autoGRA: 1`).
- [ ] Финальная сборка использует WebGL-шаблон Яндекс Игр.
- [ ] Игра запускается без авторизации и играбельна в гостевом режиме.
- [ ] Корректно работает пауза/фокус вкладки (игра и звук ставятся на паузу при потере фокуса).

## 3) Реклама и монетизация
- [x] Точка вызова interstitial реализована перед показом правил.
- [ ] Interstitial-модуль включен в PluginYG2 (`InterstitialAdv_yg`). ВАЖНО: сейчас не включен.
- [ ] Проверен реальный рекламный флоу в окружении Яндекса (open/close/error callbacks).
- [ ] Частота рекламы безопасна для модерации (без спама и принудительных циклов).
- [ ] Если есть покупки, используются только платежи через SDK Яндекса.

## 4) Модерация и безопасность контента
- [ ] Нет сломанных сценариев, софтлоков и нерабочих кнопок в цикле меню -> игра -> результаты.
- [ ] Нет ассетов без прав на использование.
- [ ] Нет запрещенного контента.
- [ ] Нет интерактивного ИИ-чата/генерации внутри игрового процесса.

## 5) Карточка игры в консоли Яндекса
- [ ] Заполнены название/описание и они соответствуют содержимому игры.
- [ ] Корректно выбраны платформы (desktop/mobile/tablet по необходимости).
- [ ] Корректно выбрана ориентация экрана.
- [ ] Заполнен возрастной рейтинг.
- [ ] Загружены промо-материалы (иконка, обложка, скриншоты).
- [ ] Выбраны языки, соответствующие локализации в игре.
- [ ] Заполнен Apple Team ID, если выбрана iOS-платформа.

## 6) Финальный smoke-тест перед отправкой
- [ ] Проверен полный маршрут: главное меню -> выбор уровня -> правила -> игра -> победа/поражение.
- [ ] Тумблеры и громкость музыки/звуков сохраняются после перезапуска.
- [ ] Interstitial показывается перед правилами при старте уровня (если модуль включен).
- [ ] Нет пропущенных ключей локализации/заглушек.
- [ ] Нет критических исключений в Unity Console и консоли браузера.
